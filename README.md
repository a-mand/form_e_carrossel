# Formulário de Inscrição e Carrossel de Imagens

Aplicação em **React** com um formulário de inscrição simples e um carrossel de imagens.

## Como executar
```bash
git clone https://github.com/a-mand/form_e_carrossel.git
cd form_e_carrossel
npm install
npm start
```
Abra http://localhost:3000.

## Tecnologias
React (Create React App), JavaScript, HTML, CSS.
